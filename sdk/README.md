# RevolaOS SDK

Headers, linker script, Make include and packer for building extensions against one revola release. Everything an extension needs is in this directory; nothing reaches into the core.

The guides, with a table of every file here, ship in `docs/` of the SDK tarball and live at [docs/sdk](https://github.com/RevolaOS/revola/tree/main/docs/sdk) in the repository. Install `build/<id>.rvx` as `/Revola/Extensions/<id>.rvx`.
